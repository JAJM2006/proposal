- To edit Homepage -
If you only want to edit the text:
    1) Go to: https://github.com/JAJM2006/spagetitii/blob/main/src/content/home/-index.md
    2) Press the pencil and make your changes. 
If you want to update the image:
    1) Go to: https://github.com/JAJM2006/spagetitii/tree/main/src/assets/profile
    2) Change the image that is named the same as the one in the text box above

- To edit Top Picks - 
If you only want to edit a pre existing Top Pick:
    1) Go to: https://github.com/JAJM2006/spagetitii/tree/main/src/content/top-picks
    2) Select what category (ie Books and Guides, Movies and TV shows, and Music and Podcasts)
    3) Find the entry you wish to update
    2) Press the pencil and make your changes. 
If you want to update the image:
    1) Go to: https://github.com/JAJM2006/spagetitii/tree/main/src/assets/top-picks
    2) Change the image that is named the same as the one in the text box above

- To add to the Vault - 
1) Go to: https://github.com/JAJM2006/spagetitii/tree/main/src/content/vault
2) Press Add File -> Create New File
3) Give it a unique title ending in ".md" (ie fitness.md)
4) Go to templates, Copy "VAULT TEMPLATE" 
5) Paste into the new file and fill out the template. 
6) Commit changes and wait.
