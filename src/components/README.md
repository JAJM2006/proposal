# This is the READ ME for the components (src) directory.
 The components directory is used to the general layout source code for each sub-dir. Most of this is self explanatory

```
src/
└── components/
        ├── about/            | 
        ├── base/             |  <-- This sub-directory contains the base layout configuration files (such as Header and Footer).
        ├── common/           |  <-- This sub-directory conatins the additonal confirguration files which are used in mutliple webpages (such as Socials)
        ├── hall-of-fame/     |
        ├── home/             |
        ├── links/            |
        ├── not-found/        |  <-- This is the "Error 404" layout config file
        ├── quotes/           |
        ├── recipes/          |
        ├── search/           |  <-- This is the "Search bar" layout config file
        ├── terms/            |  <-- This is the "Terms and Condirions" layout config file
        ├── top-picks/        |
        └── vault/            |


```
