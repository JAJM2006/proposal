# This is the READ ME for the source code (src) directory.

```

src/
├── assets/              |  The assets directory is used to hold images and documents that get referenced elsewhere.
├── components/          |  The components directory is used to the general layout source code for each sub-dir.
├── content/             |  The content directory is what is shown on each webpage. <---- This is where the actual text lies.
├── lib/                 |  The lib directory is used to hold the dependency files. 
├── pages/               |  The pages directory is used to change the design and layout of the specific webpages
├── styles/              |  The styles directory is used for site wide formatting. <---- This is where you change colour schemes
├── types/               |  This directory contains the file that is used for the searchbar and the indexing of files. 
├── content.config.ts    |  This is the general configuration file. If you make any changes elsewhere, you will most likely have to mirror said changes here.
└── env.d.ts             |  Icl I don't even know why this file exists, but removing it kills everything. I dont do Web-Dev for a reason.

```

Hope this helps!
