# Quick Cheat Sheet

- How to add a new recipe -
1) Go to the template (here): https://github.com/JAJM2006/spagetitii/blob/main/src/content/recipies/
2) Copy the template
3) Go to /src/content/recipies (here): https://github.com/JAJM2006/spagetitii/tree/main/src/content/recipies
4) Press Add file -> Create new file
5) Paste in template
6) Fill out template
7) Commit and wait

- How to edit the About -
1) Go to the file (here): https://github.com/JAJM2006/spagetitii/blob/main/src/content/about/-index.md
2) Click the pencil
3) Make your changes
4) Commit and wait

- If you want to change the photo -
1) Go to Assets/Profile (here): https://github.com/JAJM2006/spagetitii/tree/main/src/assets/profile
2) Press Add file -> Upload files
3) Edit the file name (if needed)
4) Commit the new image
5) Go to the file that references the image (here): https://github.com/JAJM2006/spagetitii/blob/main/src/content/about/-index.md
6) Click the pencil
7) Make your changes (update the image path in the frontmatter)
8) Commit and wait
